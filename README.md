Entry for make.fun competition **#171 — The Funniest Office Joke**.

> The lift stops at every floor except mine, because even the building is trying to get me to exercise.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes the joke above to `entry.txt` in the output directory.
The program is deterministic, writes nothing inside the repo, and
uses no network.
